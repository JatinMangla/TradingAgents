About this deployment

This hosted version runs the evidence tools: market data, SIP simulation and strategy backtesting. They are fast, stateless calculations over public price data — exactly what serverless is good at.

Three sections from the local dashboard are intentionally absent here — Run analysis, Reports and Past decisions. They are the multi-agent LLM pipeline, and serverless cannot host it:

  • One analysis chains many model calls over minutes; functions are cut off at 60s (Hobby) or 300s (Pro).
  • Live agent-by-agent progress needs a connection held open for the whole run.
  • The decision log and the reflection loop that scores past calls write files; a serverless filesystem is wiped between requests, so that learning would silently never happen.

Shipping them here would give you buttons that time out. Run that half locally instead: python -m webui at localhost:8000, where all six sections work.
